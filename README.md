# Duck Hunt

A small Duck Hunt style shooting game for the browser.

- **Rendering:** PixiJS 4 draws with WebGL and falls back to canvas automatically. Add `?renderer=canvas` to the URL to force the canvas path.
- **Audio:** Howler plays the sounds through Web Audio and falls back to HTML5 Audio. If neither works the game runs silently.
- **Assets:** All art and sound are generated by `scripts/generate-assets.mjs`, so there are no external files. Vite hashes and bundles them.

## Run

Needs Node.js 18 or newer.

```
npm install
npm run dev        # dev server with hot reload
npm run build      # regenerates assets, then builds to dist/
npm run preview    # serves dist/ locally
```

`dist/` uses ES modules, so serve it over HTTP (`npm run preview`) rather than opening `index.html` from disk.

## Deploy to Vercel

Import the project into Vercel and deploy with the default settings. `vercel.json`
configures Vercel to run `npm run build` and publish the generated `dist/` folder.
If deploying from a repository that contains this project in a subfolder, set
Vercel's **Root Directory** to `duck-hunt`.

## Play

Click to shoot, Enter or click to start, M to mute. Each round has 10 ducks and 3 shots per duck. Hit enough ducks to advance, hit all ten for a bonus. Miss too many and the dog laughs, and the game ends.

## Layout

```
scripts/generate-assets.mjs   draws sprites/backgrounds, packs the atlas, synthesizes WAVs -> src/assets
src/main.js                   renderer setup, input, main loop
src/assets.js                 loads the sprite atlas into PixiJS textures
src/audio.js                  Howler wrapper; picks up every src/assets/sounds/*.wav
src/config.js                 sizes and difficulty curves
src/game/Game.js              phase flow: title, intro, wave, retrieve, game over
src/game/Hud.js               score, shots, duck tracker, messages
src/entities/                 Duck, Dog and Gun (each owns its sprite and animation)
```

To add a sound, drop a `.wav` in `src/assets/sounds/` and call `audio.play('name')`. To change art, edit the generator and run `npm run assets`.
